# 🎮 Nexus – Gaming Showcase  

Nexus is a modern gaming showcase landing page designed to display popular and trending games in an attractive and interactive way.  

## ✨ Features  

- 🎮 Gaming-focused landing page  
- 🌌 Animated background  
- 🔥 Trending Games section  
- 🖼️ Horizontal game card slider  
- ✨ Interactive game cards  
- 📱 Responsive design  
- 🎨 Modern dark gaming theme  

## 🛠️ Technologies Used  

- HTML  
- CSS  
- JavaScript

## 🎯 Purpose  

This project was created as a web development project to practice HTML, CSS, JavaScript, animations, responsive design, and interactive UI elements.
